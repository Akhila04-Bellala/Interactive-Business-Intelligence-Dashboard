# Interactive Business Intelligence Dashboard

## Project Overview
Developed a multi-page interactive Business Intelligence Dashboard using Microsoft Power BI to analyze business performance across different areas.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Dashboard Pages

1. **Business Overview** – KPI cards and business performance analysis.
2. **Customer Churn Analysis** – Customer churn patterns and analysis.
3. **Regional Market Analysis** – Regional performance and market insights.
4. **A/B Testing Analysis** – Conversion performance and variant comparisons.

## Key Features
- Interactive KPI cards
- Dynamic slicers and filters
- Multiple charts and visualizations
- Multi-page dashboard
- DAX measures
- Consistent dashboard design

## Dataset
Used four related synthetic datasets provided for the internship task.

Successfully developed an interactive multi-page dashboard to explore business performance, customer behavior, regional markets, and A/B testing results.
